# DataRoom — запас прочности (чтобы не словить баги потом)

## 1. Число колонок (2–6)

### Как работает
- CMS-лист **`sections`** (или колонка `section_order` + уникальные `section`) задаёт разделы.
- Генератор считает активные разделы → ставит на `.grid` класс `cols-N` или `style="--cols: N"`.
- CSS: `grid-template-columns: repeat(var(--cols), minmax(var(--col-min), 1fr))`.

### Правила генератора
| Ситуация | Поведение |
|----------|-----------|
| 2–6 активных разделов | ровно столько колонок |
| 1 раздел | всё равно `cols-1`, по центру с `max-width` |
| 7+ разделов | **ошибка в логе + не публиковать** (лимит зафиксирован) |
| Пустой раздел (0 ссылок) | не показывать колонку |
| Длинный заголовок колонки | `word-wrap`, уменьшить `font-size` при >30 символов |

### Адаптив (не путать с desktop)
- **≥1100px** — столько колонок, сколько задал CMS.
- **<1100px** — принудительно 2 колонки (читаемость).
- **<640px** — 1 колонка.

На мониторе при 5–6 колонках: `--col-min: 200px` на экранах уже 1400px.

## 2. Подсказки (desc + tip)

| Нюанс | Решение |
|-------|---------|
| Пустой `desc` | не рендерить `<span class="desc">` |
| Пустой `tip` | не рендерить `.tip-box` |
| Очень длинный tip | `max-height` + внутренний скролл или обрезка на 400 символов в CMS |
| Узкая колонка (6 шт.) | tooltip на всю ширину ячейки, `z-index` выше соседей |
| Последняя строка внизу колонки | tooltip может обрезаться — **flip вверх** (CSS `:hover` + класс `.tip-up` от JS опционально) |

---

## 3. localStorage («часто / недавно»)

| Нюанс | Решение |
|-------|---------|
| Ссылку удалили из CMS | id не в реестре → не показываем |
| id переименовали | старый id в storage игнорируется |
| Пользователь очистил кэш | fallback на `FALLBACK_FREQ` из JS |
| Два таба одновременно | race на запись — допустимо, не критично |
| **Никогда** | хранить URL в storage |

## 4. CMS-таблица

### Лист `links`
Обязательные поля: `id`, `section`, `title`, `url`, `active`.

### Лист `sections` (рекомендуется)
| column | описание |
|--------|----------|
| `section_key` | совпадает с `links.section` |
| `title` | заголовок колонки на сайте |
| `sort_order` | порядок слева направо |
| `active` | показывать колонку |

Генератор: **сначала sections → потом links**, чтобы порядок колонок не зависел от алфавита.

### Валидация перед публикацией
- [ ] уникальные `id`
- [ ] нет пустых `url` у active=TRUE
- [ ] `section` существует в `sections`
- [ ] число активных sections 2–6
- [ ] битые url (опционально, раз в неделю)

## 5. Производительность

| Делать | Не делать |
|--------|-----------|
| Статический HTML | `doGet()` на каждый визит |
| Инлайн CSS/JS в prod Sites (один embed) | CDN шрифты |
| `defer` на скрипт | тяжёлые библиотеки |
| `<details>` нативно | свой accordion на 500 строк JS |

Оценка: 200 одновременных × ~150 KB HTML = норма для Google CDN Sites.

---

## 6. Безопасность

- CSP: `connect-src 'none'` — скрипт не стучится наружу.
- Ссылки только `https://` (и `http://` запретить в валидаторе CMS).
- `rel="noopener noreferrer"` на все `target="_blank"`.
- Права на файлы — только Drive, DataRoom не проверяет ACL.

---

## 7. Чеклист перед сменой числа колонок

1. Обновить `sections` в таблице.
2. Прогнать валидатор.
3. Сгенерировать превью с `cols-N`.
4. Проверить на 1920px и 1366px: tooltip, длинные названия, свёрнутые блоки.
5. Опубликовать.
