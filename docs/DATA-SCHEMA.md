# Схема данных CMS

Таблица — единственный источник правды. Сайт **не хранит** ссылки в БД: при публикации строки превращаются в статический HTML.

## Лист `links` (ссылки)

| Колонка | Тип | Обязательно | Куда на сайте |
|---------|-----|-------------|---------------|
| `id` | текст | да | `data-id` на `<a>` |
| `section` | текст | да | привязка к колонке (разделу) |
| `subsection` | текст | нет | группа внутри `<details>` |
| `group` | текст | нет | подзаголовок `.grp` |
| `title` | текст | да | `.item-title` |
| `desc` | текст | нет | `.desc` (кратко под названием) |
| `tip` | текст | нет | `.tip-box` (подсказка при hover) |
| `url` | URL | да | `href` (Drive, портал, `#` если черновик) |
| `sort_order` | число | нет | порядок внутри подраздела |
| `active` | TRUE/FALSE | нет | скрыть строку без удаления |
| `collapsed_default` | TRUE/FALSE | нет | свёрнутый `<details>` по умолчанию |
| `highlight` | TRUE/FALSE | нет | класс `featured` |

## Лист `sections` (колонки на странице)

| Колонка | Тип | Описание |
|---------|-----|----------|
| `section_key` | текст | ключ = `links.section` |
| `title` | текст | заголовок колонки |
| `order` | число | порядок слева направо (2–6) |
| `active` | TRUE/FALSE | показывать колонку |

Типовые ключи: `gdrive`, `services`, `reports`, `departments` — можно свои.

## Лист `config` (настройки)

| Ключ | Пример | Назначение |
|------|--------|------------|
| `video_url` | `https://…` | ссылка «Видеоинструкция» |
| `contact_url` | `mailto:…` | куда писать при отсутствии доступа |
| `contact_label` | текст кнопки | подпись в футере |
| `brand_name` | `К О М П А Н И Я` | шапка |
| `brand_sub` | подзаголовок | шапка |
| `brand_mark` | `co` | буквы в кружке |
| `firebase_sa_file_id` | ID файла на Drive | ключ SA для деплоя из меню |

## Лист `html_store` (служебный)

| Ячейка | Содержимое |
|--------|------------|
| `A1` | последний собранный HTML (бэкап для Firebase) |

Создаётся скриптом, можно скрыть лист.

## Что **не** хранится на сервере сайта

| Данные | Где живут |
|--------|-----------|
| URL файлов | только в HTML после публикации |
| «Часто / недавно» | `localStorage` браузера, **только id** |
| Права на Drive | Google Drive, не DataRoom |

Подробности edge-cases: `docs/DESIGN-EDGE-CASES.md`.
